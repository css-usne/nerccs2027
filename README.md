# NERCCS 2027 website

Static site for the Tenth Northeast Regional Conference on Complex Systems, 21 to 23 April 2027,
Roux Institute, Portland, Maine. Live at https://css-usne.github.io/nerccs2027/

Two files. `index.html` is the whole site, one page with anchor navigation. `styles.css` is the
chapter stylesheet, copied unchanged from the Womplexity Meets Northeast satellite site so the
chapter's sites look like each other.

## How to change something

Edit in the browser. There is no reason to clone this.

1. Open `index.html` here on GitHub and click the pencil icon.
2. Change the text, scroll down, commit.
3. GitHub Pages redeploys in about a minute.

For anything larger, press `.` while viewing the repo and a full editor opens in the browser.

## Deliberate non-decisions

No Jekyll, no npm, no build step, no GitHub Actions, no custom domain. Everything needed is on
GitHub's free tier for public repositories, so there is nothing to pay for, renew or keep
up to date, and nothing that can break between edits. Please keep it that way; this is
unpaid work and the maintenance budget is close to zero.
